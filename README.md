# 台中交通壅塞分析專案 🚗

本專案分析了從福田水資源回收中心至台中工業區塑膠中心的通勤壅塞情形，透過 Python 與 OpenRouteService API 實作出模擬路徑、車速變化圖與出發時間比較圖。

## 預覽網站 🌐
👉 https://oliver-reborn.github.io/taichung_traffic/

## 使用技術
- Python
- ORS API
- Folium
- Matplotlib
- SQLite
- HTML + Bootstrap + GitHub Pages

## 專案成果
- 📍 通勤模擬地圖
- 📊 不同時段車速變化圖
- ⏱️ 出發時間對通勤時間影響圖
